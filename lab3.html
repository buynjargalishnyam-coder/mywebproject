3. Media Types & Logical Operators

@media all → Бүх төхөөрөмжид

@media screen → Дэлгэц дээр

@media print → Хэвлэх үед

screen and (min-width: 700px) → Дэлгэц + хамгийн багадаа 700px

(max-width: 500px), (orientation: portrait) → OR нөхцөл

(min-width: 600px) or (hover: none) → OR логик

not print → Print биш үед

only screen and (min-width: 320px) → Зөвхөн screen
