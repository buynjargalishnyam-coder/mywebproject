CSS Properties Туршилтын ажил

1. CSS Margin

Margin нь элементийн гаднах зайг тохируулна.

Margin: 30px

2. CSS Padding

Padding нь элементийн доторх зайг тохируулна.

Padding: 40px

3. CSS Align

text-align нь текстийн байрлалыг тохируулна.

Энэ текст төвд байрласан.

4. CSS Border

Border нь элементийн эргэн тойронд хүрээ үүсгэнэ.

Border: 5px solid red

5. CSS Outline

Outline нь border-ийн гадна талд хүрээ үүсгэнэ.

Border + Outline

6. CSS Opacity

Opacity нь элементийн тунгалаг байдлыг тохируулна.

Opacity: 0.5

7. CSS !important

!important нь CSS дүрэмд давуу эрх олгоно.

Энэ текст !important ашигласан тул УЛААН өнгөтэй байна.
